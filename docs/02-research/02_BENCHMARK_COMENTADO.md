# 02 — Benchmark comentado

## Cómo leer este documento

**Relevancia** no significa “copiar”.  
Cada referencia se analiza por una decisión o tensión útil para MORA.

---

## 1. Exat Microsite — Studio Size / Codrops
**Relevancia:** MUY ALTA  
https://tympanus.net/codrops/2026/04/10/the-exat-microsite-pushing-a-typography-showcase-to-new-creative-extremes/

### Qué interesa
- Motion e interacción explican el sistema tipográfico en vez de decorarlo.
- Alterna pasajes expresivos y tranquilos.
- Las animaciones fuera de pantalla se pausan.
- Smooth scrolling se utiliza selectivamente.
- En mobile simplifica interacciones en lugar de replicarlas.
- Performance fue parte del diseño desde temprano.

### Traducir a MORA
- Cada área debe “demostrar” su materia mediante movimiento.
- Diseñar mobile como traducción.
- Ritmo con pausas.
- No animar por abundancia.

### No copiar
- La dependencia de tipografía variable como concepto.
- Su stack o smooth scroll por defecto.

## 2. Pell Mell — Codrops
**Relevancia:** MUY ALTA  
https://tympanus.net/codrops/2026/03/27/pell-mell-crafting-a-visual-exploration-platform-with-editorial-rhythm/

### Qué interesa
- Parte de la crítica a portfolios “correctos pero sin feeling”.
- Apariencia libre/editorial sobre un sistema subyacente estricto.
- Interacciones pequeñas, coherentes.
- Navegación discreta pero disponible.
- Mobile tratado como experiencia completa.
- Contacto desarrollado como experiencia, no trámite.

### Traducir a MORA
- Sistema editorial invisible.
- Composición aparentemente espontánea pero gobernada por reglas.
- Contacto final diseñado.
- Mobile con personalidad equivalente.

### Cuidado
- No adoptar un loader ornamental solo porque forma parte del caso.

## 3. Stefan Vitasović Portfolio 2025 — Codrops
**Relevancia:** ALTA  
https://tympanus.net/codrops/2025/03/05/case-study-stefan-vitasovic-portfolio-2025/

### Qué interesa

## 4. Pedro Ajo
**Relevancia:** ALTA  
https://pedroajo.com/
https://www.siteinspire.com/website/12869-pedro-ajo

### Qué interesa
- Tipografía y sistema editorial sostienen identidad sin necesidad de sobreanimar.
- Organización de trabajos como piezas de un sistema.
- Blanco/negro y jerarquía demuestran cuánto puede hacer una estructura rigurosa.

### Traducir a MORA
- Captions, numeración, figuras, metadata mínima.
- Jerarquía de tipos muy deliberada.
- “Menos componentes, mejores relaciones.”

### No copiar
- Austereza B&N total: MORA necesita materia, textura y fucsia.

## 5. Buena Suerte
**Relevancia:** ALTA / MEDIA  
https://buena-suerte.studio/

### Qué interesa
- Lenguaje de figuras (“fig. 1”, “fig. 2”) genera tono editorial sin volver la UI académica.
- Portfolio + índice conviven.
- Componentes suficientemente flexibles para muchos proyectos.

### Traducir a MORA

- Una galería puede tener narrativa y también índice.

## 6. Monolith Studio
**Relevancia:** MUY ALTA para Tattoos  
https://monolithstudio.com/
https://artemiilebedev.com/journal/bringing-tattoos-into-the-digital-era
https://artemiilebedev.com/work/monolith-studio

### Qué interesa
- Trata tattoo como arte/cultura, no como mero servicio.
- Editorialidad y gran imagen.
- Sistema unificado para artistas distintos.
- Booking entendido como parte central del producto.
- Evita depender de la típica fórmula “galería + bio + formulario”.

### Traducir a MORA
- Tattoos merece una presencia cultural/visual seria.
- La consulta debe pedir el contexto que realmente ayuda a Mora.
- La obra tiene prioridad sobre ornamentos.

### No copiar
- Monolito 3D.
- Monumentalidad/gótico como identidad madre.
- Su escala de estudio multiartista.

## 9. La Tatuajería
**Relevancia:** MEDIA  
https://latatuajeria.com/

### Qué interesa
- Propuesta concreta rápidamente.
- CTA de cita visible.
- Galería + equipo + FAQ + información de higiene.

### Traducir a MORA
- La capa operativa del tattoo debe ser extremadamente comprensible.
- La dirección artística no debería impedir saber cómo agendar.

### No copiar

- Formulario largo: MORA eligió WhatsApp y sin formularios V1.

**Relevancia:** ALTA conceptual / BAJA como implementación V1

- Cada disciplina puede sentirse como una escena/ambiente.

### No copiar
- Three.js/WebGL/Blender como punto de partida.
- Tres meses de complejidad técnica para resolver algo que podemos expresar con medios más económicos.

# Conclusión del benchmark

Las referencias más útiles no comparten una estética. Comparten una disciplina:

- restringen recursos;
- repiten motivos;
- sostienen estructura;
- adaptan mobile;
- tratan performance como parte del diseño;
- permiten que el contenido real tenga peso.

**MORA debería parecer libre sin estar construida libremente.**
