# 04 — Moodboard funcional

No fija fuentes ni colores exactos. Describe sensaciones, materiales y relaciones.

## 1. Sistema madre MORA

### Base
- carbón / casi negro;
- blanco de alto contraste;
- fucsia como acento escaso y reconocible;
- borde/verde/marrón como campos ambientales opcionales.

### Composición
- grid riguroso;
- asimetría;
- grandes áreas de aire;
- piezas que ocasionalmente rompen columnas;
- metadata pequeña;
- titulares de escala alta;
- notas/captions como contrapunto.

### Tacto
- grano real;
- piel;
- papel;
- tinta;
- masa;
- metal;
- sombras;
- luz de taller/proceso.

### Regla
La textura se captura o produce con material real siempre que sea posible.  
No convertirla en una colección de overlays de “grunge”.

# 2. Acto Tattoos

## Palabras
precisión / tinta / decisión / detalle / piel / marca / pulso

## Imagen
- macro;
- aguja sin fetichizar;
- stencil;
- manos;
- resultado;
- sombras;
- detalles de línea.

## Motion
- reveal como trazo;
- expansión o absorción mínima de tinta;
- máscara que sigue una línea;
- cambio de foco;
- aparición lenta de sombra/relleno.

## Sonoridad visual
seca / precisa / de alto contraste

## Evitar
- fuego;
- calaveras;
- blackletter automática;
- estética “danger”;
- gore;
- exceso de ruido.

# 3. Acto Pastelería

## Palabras
capa / sabor / corte / relleno / textura / compartir / sorpresa

## Imagen
- macro de relleno;
- sección cortada;
- manga;
- crema;
- chocolate;
- masa;
- manos trabajando;
- producto pequeño a escala humana.

## Motion
- capas que se revelan;
- piping/trazo;
- corte;
- wipe orgánico;
- pequeñas partículas/migas muy controladas;
- cambio de temperatura visual.

## Sonoridad visual
más blanda / cercana / táctil / indulgente

## Evitar
- pastel infantil;
- sticker overload;
- ilustración cute por defecto;
- rosa como código “femenino”.

# 4. Acto Sofit

## Palabras
ritmo / fuerza / técnica / respiración / repetición / progresión / acompañamiento

## Imagen
- repetición de un movimiento;
- preparación;
- corrección técnica;
- mano señalando/explicando;
- detalles de peso;
- respiración;
- desplazamiento;
- planos amplios de espacio.

## Motion
- loop corto de repetición;
- tensión/relajación;
- timeline;
- pequeño contador/ritmo;
- elementos que ganan estabilidad con el scroll.

## Sonoridad visual
controlada / energética / respirada / física

## Evitar
- neón;
- llamas;
- “beast mode”;
- interfaces de smartwatch ficticias;
- stock fitness;
- copy de “mejor versión”.

# 5. Sobre Mora

## Ritmo
baja el tempo.

## Imagen
- perfil;
- trabajando;
- rostro completo selectivo;
- una escena más personal sin invadir intimidad.

## Diseño
- más texto;
- menos efectos;
- pequeñas huellas de todas las materias;
- fotografía sincera pero producida.

## Función
reconectar los tres actos con una persona real.

# 6. Contacto

## Ritmo
cierre, no formulario.

## Posible gesto
Los tres vocabularios materiales convergen:
- trazo;
- capa;
- ritmo.

Mensaje:
“¿Ya sabés qué querés?” / “¿Todavía lo estás pensando?”

Dos caminos, mismo WhatsApp.

# 7. Tipografía — criterio de investigación posterior

Se necesitan probablemente dos roles:

### Display
- carácter;
- grandes tamaños;
- capaz de funcionar como forma;
- no necesariamente “artística” de manera obvia.

### Texto / interfaz
- excelente lectura;
- natural;
- contemporánea;
- no corporativa.

No elegir ahora por estética aislada. Probar con copy real.

---

# 8. Movimiento global

Una escena no debería usar más de 1–2 ideas fuertes simultáneamente.

Preferencia:
- transform;
- opacity;
- clip/mask;
- SVG;
- video breve;
- parallax mínimo.

WebGL:
solo si aparece una idea imposible de expresar bien por medios más livianos.
