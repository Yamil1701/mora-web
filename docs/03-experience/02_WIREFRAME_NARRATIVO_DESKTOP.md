# 02 — Wireframe narrativo — Desktop

Las alturas son aproximaciones narrativas, no medidas finales.

## D0 — Header

```text
┌──────────────────────────────────────────────────────────────┐
│ MORA        Tattoos  Pastelería  Sofit  Sobre      WhatsApp │
└──────────────────────────────────────────────────────────────┘
```

Ligero en hero, más contrastado durante contenido, compactable al scroll. Puede probarse un indicador `01/03` durante los actos.

## D1 — Hero — 100–130vh

```text
┌──────────────────────────────────────────────────────────────┐
│                     [fragmentos de materia]                  │
│                                                              │
│  MORA                                                        │
│  Expresión en todas sus formas.                              │
│  En la piel, en los sabores y en el movimiento.              │
│                                                              │
│  Tattoos      Pastelería      Sofit                    ↓     │
└──────────────────────────────────────────────────────────────┘
```

No centrar todo por defecto. Probar MORA parcialmente fuera de grid, copy anclado y media fragmentada. Entrada breve; nada que impida leer en 2–3 s.
