# 00 — Decisión ejecutiva

## La Home no es una landing tradicional

La arquitectura funcional sigue siendo comprensible:

```text
Hero → Tattoos → Pastelería → Sofit → Proyectos / recorrido → Sobre Mora → Contacto
```

Pero la experiencia debe sentirse como un recorrido continuo. El visitante no debe percibir “terminé una sección, ahora viene otra card”, sino “la misma identidad acaba de cambiar de materia”.

## Gramática de cada acto

1. **Sensación** — primero se siente la disciplina.
2. **Reconocimiento** — aparece nombre y frase clara.
3. **Prueba** — trabajo/proceso real.
4. **Significado** — una idea breve sobre cómo trabaja Mora.
5. **Acción** — CTA para decidido + camino para exploratorio.
6. **Transición** — el universo cambia de materia.

## Ritmo global

```text
APERTURA
  ↑ tensión
TATTOOS
  ↑↑ primer pico
PAUSA
  ↓
PASTELERÍA
  ↑ segundo pico, más sensorial
PAUSA
  ↓
SOFIT
  ↑↑ tercer pico, más cinético
DESCENSO
  ↓↓
PROYECTOS / SOBRE MORA
  calma
CONTACTO
  cierre firme
```

La Home necesita silencios. Intensidad constante = fatiga.

## Firma recurrente

Hipótesis: un **trazo** que reaparece de forma limitada como línea de stencil, borde, recorrido de manga, guía técnica, subrayado o indicador. No será un objeto animado permanente.

## Transiciones

Evitar morphs literales forzados. Preferir **match cuts de gesto, textura o movimiento real**.

### Tattoo → Pastelería
Una mano ejecuta un gesto controlado con máquina/stencil y corta a una mano haciendo un gesto de manga o decoración en la misma dirección. La continuidad está en mano + precisión + dirección.

### Pastelería → Sofit
Una mano ejerce presión/control sobre manga o espátula y corta a una mano agarrando peso o guiando una postura. La continuidad está en fuerza + control + repetición.

## Regla de claridad

Antes de terminar el primer scroll debe quedar claro:
- MORA es una persona/marca;
- existen Tattoos / Pastelería / Sofit;
- la página se puede recorrer;
- existe un camino de contacto.
