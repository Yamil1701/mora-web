# 08 — Criterios de aprobación

## Claridad
- [ ] MORA se identifica rápido.
- [ ] Tattoos/Pastelería/Sofit aparecen temprano.
- [ ] Cada acto se entiende sin explicación externa.
- [ ] Preview y subpágina se distinguen.

## Identidad
- [ ] No parece plantilla.
- [ ] No parece web exclusiva de tattoo.
- [ ] No parece pastelería infantil.
- [ ] No parece fitness genérico.
- [ ] Los tres actos son una sola marca.
- [ ] Hay al menos un gesto memorable propio.

## UX
- [ ] Navegación recuperable.
- [ ] WhatsApp accesible.
- [ ] CTA visible.
- [ ] No scroll-jacking frustrante.
- [ ] No false floor.
- [ ] No interacción crítica hover-only.

## Mobile
- [ ] Coreografía propia.
- [ ] No es desktop apilado sin criterio.
- [ ] No depende de horizontal scroll.
- [ ] Targets táctiles adecuados.
- [ ] Media optimizada.

## Motion
- [ ] Cada efecto tiene función.
- [ ] Hay pausas.
- [ ] Reduced motion funciona.
- [ ] No más de 1–2 ideas fuertes simultáneas.
- [ ] Transición de materias no parece gimmick.

## Contenido
- [ ] Trabajo real protagonista.
- [ ] No claims profesionales dudosos.
- [ ] No testimonios ficticios publicados.
- [ ] Piercing no diluye Tattoos en Home.

## Performance
- [ ] LCP no depende de media innecesariamente pesada.
- [ ] Actos posteriores no descargan todo al inicio.
- [ ] CLS controlado.
- [ ] Interacción inmediata.
