# Dirección visual y motion — base previa a investigación

Este documento NO define un diseño final. Define límites y tensiones que la investigación debe respetar.

## 1. Sensación

Buscar:
- oscuridad viva;
- contraste;
- textura;
- materia;
- tactilidad;
- energía;
- composición editorial;
- gesto artístico;
- fotografía preparada;
- detalle humano.

Evitar:
- corporate;
- SaaS;
- portfolio-template;
- infantil;
- pastel genérico;
- neon fitness;
- tattoo gótico automático;
- collage caótico sin jerarquía;
- "landing GSAP" reconocible por efectos de librería.

## 2. Paleta exploratoria

Acento confirmado:
- fucsia.

Disponibles para explorar:
- negro/carbón;
- blanco;
- bordó;
- verde oscuro;
- verde claro;
- marrón oscuro.

Evitar:
- fluor dominante;
- amarillo;
- naranja chillón;
- crema dominante.

Las áreas pueden modificar atmósfera sin romper la identidad.

## 3. Materialidad por área

No se trata de asignar "un color por servicio".

### Tattoos
Material:
- tinta;
- piel;
- aguja/máquina;
- stencil;
- líneas;
- sombras;
- guantes;
- papel.

Sensación:
- precisión;
- decisión;
- detalle;
- contraste.

### Pastelería
Material:
- chocolate;
- crema;
- masa;
- manga;
- corte;
- relleno;
- migas;
- brillo;
- capas.

Sensación:
- textura;
- deseo;
- cercanía;
- ritmo más sensorial.

### Sofit
Material:
- respiración;
- tensión;
- peso;
- metal;
- desplazamiento;
- repetición;
- músculos en movimiento;
- cronología/progreso.

Sensación:
- energía;
- control;
- aprendizaje;
- fuerza;
- acompañamiento.

## 4. Fotografía

No hero de retrato obligatorio.

Mora puede aparecer:
- trabajando;
- fragmentada;
- de perfil;
- en planos de manos;
- cuerpo en movimiento;
- rostro completo selectivo.

Evitar:
- hablar a cámara;
- exceso de retrato;
- fotos casuales sin preparar cuando rompen identidad;
- retoque que falsee trabajos.

IA permitida para:
- normalización;
- limpieza;
- encuadre;
- luz;
- ruido;
- consistencia.

No usar IA para inventar resultados o modificar sustancialmente trabajos presentados como reales.

## 5. Motion

Herramientas probables:
- GSAP;
- ScrollTrigger;
- CSS.

Posibles recursos a investigar:
- transformaciones de materia;
- tipografía cinética;
- cambios de ritmo;
- reveals;
- transiciones entre disciplinas;
- desplazamiento horizontal puntual;
- máscaras;
- recortes;
- texturas reactivas;
- entrada de palabras como elemento físico.

## 6. Regla "arte"

Ejemplo solicitado por Mora:
- en Tattoos, la palabra "arte" puede recibir gesto de tinta;
- en Pastelería, elementos escritos/dibujados con gesto similar a manga pastelera.

Esto se toma como dirección conceptual, no obligación literal.

La investigación decidirá:
- si funciona;
- cuándo;
- cuánto;
- qué alternativa es más sofisticada.

## 7. Mobile

Mobile debe traducir:
- ritmo;
- textura;
- cercanía;
- transición de áreas;
- personalidad.

Puede renunciar a:
- composiciones muy horizontales;
- escenas complejas;
- parallax intenso;
- secuencias largas.

No puede renunciar a:
- identidad;
- contraste;
- claridad;
- emoción;
- contacto.
