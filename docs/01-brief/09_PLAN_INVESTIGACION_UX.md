# Próxima fase — Investigación UX y Dirección Creativa

## Objetivo

Evitar que MORA termine como una landing genérica y construir una experiencia sustentada en:
- buenas prácticas UX;
- referencias contemporáneas;
- interacción relevante;
- identidad propia;
- performance;
- accesibilidad;
- adaptación mobile.

## Enfoque

No buscar "una web para copiar".

Buscar:
- patrones;
- decisiones;
- momentos;
- errores;
- maneras de resolver problemas concretos.

## Fuentes de investigación

### UX / usabilidad
- fuentes primarias y autoridades de UX;
- accesibilidad;
- mobile;
- navegación;
- jerarquía;
- interacción;
- motion.

### Performance
- Core Web Vitals;
- carga de imágenes/video;
- impacto de GSAP;
- estrategia responsive.

### Inspiración creativa
- portfolios;
- estudios;
- artistas;
- tattoo;
- gastronomía;
- fitness/wellness;
- editorial;
- sitios experimentales;
- showcases de motion.

### Bibliotecas técnicas
- ReactBits;
- Tailark;
- componentes/patrones de código;
- usados solo cuando resuelvan una necesidad.

## Muestra

Objetivo aproximado:
**15–25 sitios** suficientemente distintos.

No concentrarse solo en competidores locales.

- virtud;

### 2. Biblioteca de patrones MORA

- CTA;

### 4. Moodboard funcional
