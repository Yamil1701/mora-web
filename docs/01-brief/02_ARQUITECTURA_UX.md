# Arquitectura y principios UX

## Modelo híbrido

La Home no será un catálogo de tarjetas. Será una pieza narrativa que introduce las tres áreas con suficiente profundidad emocional para que cada preview resulte memorable.

Las subpáginas permiten:
- profundizar;
- compartir URLs específicas;
- mejorar SEO;
- atender distintos niveles de intención;
- ofrecer información operativa sin cargar la Home.

## Navegación

Debe existir una navegación clara incluso cuando la experiencia sea experimental.

Principio:
**sorprender sin desorientar.**

La experiencia puede tener capas artísticas, pero el usuario debe poder responder siempre:
- dónde estoy;
- qué ofrece Mora;
- cómo profundizo;
- cómo contacto;
- cómo vuelvo.

## Dos niveles de intención

La web debe diferenciar:

### Usuario decidido
Ya sabe qué quiere y busca:
- precio;
- disponibilidad;
- proceso;
- turno;
- contacto inmediato.

### Usuario exploratorio
Tiene curiosidad o una idea poco definida y necesita:
- inspiración;
- guía;
- entender opciones;
- ganar confianza;
- conversar.

Esto debe reflejarse en CTAs, por ejemplo:
- **Contame tu idea**
- **Consultar**
- **Ya sé qué quiero**
- **Necesito orientación**

## Contacto

- WhatsApp Business prioritario.
- Instagram profesional secundario.
- botones contextuales;
- WhatsApp persistente;
- página /contacto;
- teléfono/número puede mostrarse además del botón;
- no formularios en V1.

## Desktop / mobile

### Desktop
Mayor expansión visual, composiciones complejas y secuencias GSAP más ricas.

### Mobile
Debe tener:
- lectura inmediata;
- targets táctiles correctos;
- contenido visible sin esperar;
- motion más breve;
- ritmo propio;
- transiciones simplificadas;
- CTA accesible.

No se acepta "desktop encogido".

## Principios UX preliminares

1. La sorpresa nunca debe ocultar la oferta.
2. Cada una de las tres áreas necesita un momento memorable propio.
3. El contenido importante no depende de que una animación termine.
4. El usuario puede contactar rápidamente desde cualquier estado.
5. El scroll no debe sentirse secuestrado.
6. La navegación mantiene orientación.
7. La fotografía debe demostrar trabajo real.
8. El movimiento refuerza significado, no rellena espacio.
9. Mobile tiene dirección propia.
10. Los CTAs no rompen la inmersión: aparecen en el momento correcto.
11. La accesibilidad no se sacrifica por espectáculo.
12. La identidad visual se mantiene aun cuando cambie el ambiente de cada disciplina.
13. El usuario exploratorio recibe guía; el decidido recibe velocidad.
14. La página debe ser entendible aun sin motion.
15. La experiencia debe poder recordarse por algo específico de MORA, no por un componente de moda.

## Nivel experimental

Objetivo: 7–8 / 10.

Esto permite:
- composiciones asimétricas;
- tipografía expresiva;
- storytelling por scroll;
- transición de materiales;
- interacción con imágenes;
- efectos de textura;
- uso deliberado de GSAP.

No permite:
- navegación críptica;
- loader ornamental largo;
- scroll-jacking injustificado;
- contenido ilegible;
- efectos que degraden móvil de forma severa.
