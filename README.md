# MORA Web

Sitio personal/profesional de **MORA (Sofía Agüero)**.

> **Expresión en todas sus formas.**  
> En la piel, en los sabores y en el movimiento.

## Estado

Baseline técnico y documental previo al **Prototype 01**.

Todavía no hay una identidad visual ni una implementación UX definitiva. Los estilos actuales son deliberadamente neutrales.

## Stack base

- Astro 7
- TypeScript
- GSAP / ScrollTrigger para motion cuando tenga una función justificada
- Sitio estático en V1
- Sin backend ni CMS en el baseline

## Requisitos

- Node.js 22.12.0 o superior, versión par soportada por Astro.

## Desarrollo

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```
